# 個別絵教材の画面改善（2026-09-09）

対象は低学年の方眼・ジャンプ・魚・おえかき、高学年の方眼・仕分け・フリーキック・パターンの8教材。

承認済み画面案に基づき、明るい背景、折りたたみ式の学習説明、命令と動作結果を比較できる配置、大きな操作ボタンへ統一する。狭い画面では縦スクロールで操作する。既存の教材画像、学習上必要な命令、再実行・リセット操作を保持する。

## パターンアートラボ

正解には辺の長さ x=80、角度 θ=60°、個数 n=6 が必要。六角形が閉じるだけでは正解にしない。目標と実行結果は同じ座標縮尺で描き、大きさの違いを比較できるようにする。形と個数が合っていても辺の長さが違う場合は現在値と目標値を表示し、正解演出を出さない。設定時の案内・ヒントにも大きさの条件を反映する。

## 方眼教材

壁へ移動する命令で停止し、後続の移動・色ぬりを実行しない。キャラクターは壁の直前に留まり、衝突した壁と命令を赤色と記号で示す。低学年は命令の枚数、高学年は呼び出し回数と命令番号を表示する。高学年の冒頭に低学年の方眼教材へのリンクを置く。

## 仕分け

失敗した最初の荷物について、正しい行き先と実際の行き先を表示する。結果の説明と同じ荷物を対象にする。ルール編集後は前回の比較表示を消す。

## 検証

単体テストでパターンのサイズ違い（20/50/60/79/81/100/120）を不正解と確認。方眼の衝突位置、後続命令停止、3回目の呼び出しの識別も確認する。

ブラウザーで低学年4教材の見本実行、上下学年の衝突表示、下位教材リンク、仕分け失敗の比較、キックの初回失敗、パターンのサイズ不一致／一致を確認。表示証跡は `output/lesson-implementation-2026-09-09/`。Node v20.19.0で `npm test` と `npm run build` 成功。

## 連続実行モードの廃止

「停止するまで繰り返し実行する」ボタンと実行処理を削除する。通常の実行は1回で終了する。命令単位の×2、魚のルール回数、パターンの個数nなど学習内容の繰り返しは保持する。フリーキックの有限の履歴再生は独立した操作として保持する。

## 正解表示の簡素化

正解カードは最大幅340pxの白背景と緑のチェックマークにする。紙吹雪、多色の飾り、黄色い背景、回転・大幅な拡大を廃止する。220msの短いフェードと6pxの移動で表示し、動きを減らす設定ではアニメーションしない。タップで閉じる操作と自動終了を維持する。

## 方眼のルール配置

低学年の方眼教材も他の低学年教材と同じ共通レイアウトを使用する。「できたルール」はステージの下に置き、命令カードを左から右へ順番に並べる。幅が足りない場合は次の行へ折り返す。
